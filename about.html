About Decodex

A free Base64 tool for everyday UTF-8 text.

A small tool for everyday text

Decodex helps you encode text into Base64 and decode Base64 back into readable UTF-8 text. It is useful for checking API values, understanding encoded snippets, and learning how Base64 works.

What you can do

  • Encode and decode Korean, English, emoji, and other UTF-8 text.
  • Decode Base64URL, missing padding, and strings containing spaces or line breaks.
  • Convert automatically as you type, or switch to manual conversion.
  • Copy the result and choose English or Korean.

How it works

Conversion runs in your browser, without an account or a conversion server. Decodex does not send your input or output to its analytics. Google Analytics measures site visits; read our privacy policy for details.

Know the limits

This tool handles UTF-8 text. It does not preview images, PDFs, or other binary files. Base64 is reversible encoding, not encryption: an encoded password or token is still sensitive.

Project and feedback

Decodex is maintained by jinsu100. You can view the source code on GitHub or report an issue or suggest an improvement.
