Report a problem or share an idea for the tool.

Report a bug or suggest a feature

Use the project’s GitHub Issues page to contact the maintainer, jinsu100. A GitHub account is required to submit an issue.

Open a GitHub issue →

View existing issues to see whether someone has already reported the same problem.

What to include

  • The page you used: encoder or decoder.
  • Your browser and the steps that caused the problem.
  • What you expected, and the error message or result you received.
  • A short sample with no personal or confidential information, if needed.

Before you submit

GitHub issues and replies are public. Do not include passwords, API tokens, personal information, or screenshots containing private data. There is no contact form or file upload on Decodex.

Privacy questions

You can also ask general questions about this site’s privacy policy through GitHub Issues. Keep personal details out of public posts. GitHub handles submitted information under its privacy statement.
