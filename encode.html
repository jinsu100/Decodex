Encoding, explained

Base64 represents data as text. It is not encryption and doesn't keep sensitive information secret.

How to encode text to Base64

  1. Enter or paste your text into the input box.
  2. Click Encode Base64, or press Ctrl+Enter (⌘+Enter on Mac).
  3. Click Copy result to copy the Base64 string.

For example, Hello becomes SGVsbG8=. Text is first converted to UTF-8 bytes, so Korean, emoji and other Unicode characters are supported.

Base64 encoding questions

What format does this encoder produce?

It produces standard Base64 using letters, digits, plus and slash, with equals signs for padding when needed. The output contains no added line breaks.

Can I encode a file with this tool?

This tool encodes text only, up to 5 MB of UTF-8 data. Pasting a filename does not encode the file contents.

Does Base64 make text smaller or keep it secret?

No. Base64 usually makes byte data about one-third larger, plus padding. Anyone can decode it; it is not encryption.
