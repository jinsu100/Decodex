Solucionar errores de Base64

Decodificar Base64 →Codificar Base64 →

Si una cadena no se convierte, elimina comillas, signos adicionales y el prefijo de una URL de datos; pega solo la parte Base64. El relleno = solo puede aparecer al final. Una longitud con resto 1 al dividir entre 4 es inválida. Los espacios, saltos de línea y caracteres de Base64URL - y _ se aceptan. Un error UTF-8 puede indicar datos binarios o una codificación distinta: UTF-8 es el valor predeterminado. Si el texto es ilegible, elige la codificación original.

SGVsbG8= → Hello
SGVsbG8 → Hello
SGVs bG8= → Hello

Base64 es una representación reversible de datos, no un cifrado. No protege contraseñas ni otros secretos.
