Decodex (decodex.fyi), maintenu par jinsu100, convertit le texte dans le navigateur sans conserver d’historique des conversions sur le serveur. La copie utilise le presse-papiers de l’appareil. Google Analytics peut traiter les adresses des pages, sources de visite, horaires, navigateur, appareil, localisation approximative et événements d’utilisation ; il utilise des cookies comme _ga.

Les événements contiennent le succès ou l’échec, le mode, la langue, la conversion automatique ou manuelle et des catégories fixes d’erreurs, jamais les textes, résultats, nombres de caractères ou messages d’erreur. Les conversions automatiques sont comptées après 1,5 seconde sans modification. Ne placez aucun secret dans les URL.

La langue et le thème choisis sont enregistrés localement ; sinon, les préférences du navigateur ou de l’appareil sont utilisées. Vous pouvez effacer les données du site et bloquer les requêtes d’analyse dans le navigateur. GitHub Pages héberge le site et peut traiter les adresses IP et les requêtes.

Google et GitHub appliquent leurs propres politiques et peuvent traiter les données dans d’autres pays ; la conservation dépend de leurs réglages. Les publications GitHub Issues sont publiques. Aucune publicité n’est actuellement affichée.

Cette page sera actualisée si les services changent. Effacer les données locales ne supprime pas celles déjà traitées par des prestataires externes.
