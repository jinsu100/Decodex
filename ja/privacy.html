jinsu100が管理するDecodex（decodex.fyi）はブラウザー内で変換し、サーバーに変換履歴を保存しません。 コピーには端末のクリップボードを使います。 Google AnalyticsはページURL、参照元、アクセス時刻、ブラウザー、端末、おおよその地域、利用イベントを処理する場合があり、_gaなどのCookieを使用します。

イベントには成功・失敗、モード、言語、自動・手動の区分、固定のエラー分類が含まれますが、入力、結果、文字数、エラーメッセージは含まれません。 自動変換は結果が1.5秒間変わらなかった場合に計測します。 URLに秘密情報を入れないでください。

選択した言語とテーマはローカルに保存し、未選択の場合はブラウザーや端末の設定を使います。 ブラウザーでサイトデータの削除や解析リクエストのブロックができます。 GitHub Pagesがサイトを配信し、IPアドレスやリクエスト情報を処理する場合があります。

GoogleとGitHubには各社の方針が適用され、国外で処理される場合があります。 保存期間は各サービスの設定によります。 GitHub Issuesの投稿は公開されます。

現在広告はありません。 サービスの変更時は本ページを更新します。 ローカルデータを削除しても、外部事業者が処理済みの情報は削除されません。
