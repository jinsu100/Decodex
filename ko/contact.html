오류 신고와 기능 제안

프로젝트의 GitHub Issues를 통해 운영자 jinsu100에게 문의할 수 있습니다. 문의 작성에는 GitHub 계정이 필요합니다.

GitHub에서 문의 작성 →

기존 문의 보기에서 같은 문제가 이미 등록되어 있는지도 확인할 수 있습니다.

이 내용을 알려주시면 도움이 됩니다

  • 사용한 페이지: 인코더 또는 디코더
  • 브라우저 종류와 문제가 발생한 순서
  • 예상한 동작과 실제 결과 또는 오류 메시지
  • 필요한 경우 개인정보와 비밀 정보가 없는 짧은 예시

작성하기 전에

GitHub 문의와 답변은 누구나 볼 수 있습니다. 비밀번호, API 토큰, 개인정보, 비공개 내용이 담긴 스크린샷은 올리지 마세요. Decodex에는 별도의 문의 입력 폼이나 파일 업로드 기능이 없습니다.

개인정보 관련 질문

이 사이트의 개인정보처리방침에 관한 일반적인 질문도 GitHub Issues로 전달할 수 있습니다. 공개 게시물에는 개인적인 정보를 적지 마세요. GitHub에 작성한 정보에는 GitHub 개인정보처리방침이 적용됩니다.
