Base64란?

Base64는 데이터를 텍스트로 표현하는 방식입니다. 암호화가 아니며 민감한 정보를 보호하지 않습니다.

Base64 인코딩 사용법

  1. 입력 칸에 텍스트를 입력하거나 붙여넣으세요.
  2. 자동으로 인코딩됩니다. 자동 변환을 끈 경우 인코딩하기를 누르거나 Ctrl+Enter(맥: ⌘+Enter)를 누르세요.
  3. 결과 복사를 눌러 Base64 문자열을 복사하세요.

예를 들어 Hello는 SGVsbG8=로 변환됩니다. 텍스트를 먼저 UTF-8 바이트로 변환하므로 한글·이모지 등 유니코드 문자를 지원합니다.

Base64 인코딩 자주 묻는 질문

어떤 형식의 Base64를 생성하나요?

영문자·숫자·더하기·슬래시를 사용하는 표준 Base64를 생성하며, 필요한 경우 등호로 패딩을 붙입니다. 결과에 줄바꿈을 추가하지 않습니다.

파일도 인코딩할 수 있나요?

이 도구는 UTF-8 기준 최대 5MB의 텍스트를 변환합니다. 파일 이름을 붙여넣어도 파일 내용이 인코딩되지는 않습니다.

Base64는 크기를 줄이거나 정보를 숨겨 주나요?

아니요. Base64는 일반적으로 바이트 데이터보다 약 3분의 1 커지고 패딩이 추가됩니다. 누구나 디코딩할 수 있으며 암호화가 아닙니다.

Base64 문자열을 읽고 싶으신가요? Base64를 텍스트로 디코딩하세요.

변환은 브라우저에서 처리하며 입력 텍스트를 변환 서버로 보내지 않습니다. Google 애널리틱스는 사이트 방문을 측정합니다.

Base64와 Base64URL 차이 — URL 안전 문자·패딩·디코딩 예제

Base64와 Base64URL의 + /, - _ 차이와 패딩 생략 조건을 예제로 비교합니다. URL에서 문자가 바뀌는 이유와 UTF-8 디코딩 방법을 확인하세요.

Base64 끝의 =와 == 의미 — 패딩 오류·생략 규칙 설명

Base64 패딩 =와 ==의 의미를 f·fo·foo 예제로 설명합니다. 패딩 없는 문자열의 복원, 길이 오류, Zg와 Zg=의 차이를 확인하세요.
