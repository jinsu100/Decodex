개인정보처리방침

변환하는 문자와 사이트 방문 정보가 처리되는 방식을 안내합니다.

시행일 및 최종 수정일: 2026년 10월 2일

이 방침의 적용 범위

GitHub 사용자 jinsu100이 운영하는 decodex.fyi의 Decodex 서비스에 적용됩니다.

입력한 문자와 변환 결과

인코딩과 디코딩은 사용자의 브라우저에서 처리됩니다. 변환 도구는 입력과 결과를 변환 서버로 업로드하거나 애널리틱스 이벤트로 전송하지 않으며, 서버에 변환 기록을 저장하지 않습니다. 결과 복사를 누르면 기기의 클립보드에 저장됩니다. 브라우저나 기기는 자체 설정에 따라 입력란 또는 클립보드 내용을 보관할 수 있습니다.

사이트 방문 통계

사이트 이용 현황을 파악하고 개선하기 위해 Google Analytics를 사용합니다. 페이지 주소, 유입 사이트, 방문 시각, 브라우저와 기기 정보, 대략적인 위치, 이용 이벤트 등이 처리될 수 있습니다. 기능 사용 통계에는 인코딩·디코딩 성공 및 실패, 결과 복사 횟수와 변환 모드, 화면 언어, 자동·수동 변환 구분, 정해진 오류 분류를 기록합니다. 입력 문자, 변환 결과, 문자 수, 오류 메시지 내용은 이러한 이벤트에 포함하지 않습니다. 자동 변환은 입력이 멈춘 뒤 1.5초 동안 결과가 유지된 경우 집계하며, 중간 결과는 제외합니다. 방문을 구분하는 데 _ga 등의 쿠키가 사용됩니다. 페이지 주소는 통계에 포함될 수 있으므로 URL에 비밀 정보를 넣지 마세요.

Google은 자체 정책에 따라 정보를 처리합니다. 쿠키의 유지 기간과 통계 보관 기간은 서비스 설정 및 브라우저의 동작에 따라 달라집니다. 파트너 사이트에서 수집한 정보의 Google 사용 방식과 Google 개인정보처리방침을 확인할 수 있습니다.

언어 설정

기본 주소에서는 브라우저 언어에 맞는 지원 언어를 선택하며, 지원하지 않는 언어는 영어로 표시합니다. 언어별 주소로 직접 방문하면 해당 언어를 유지합니다. 사용자가 직접 선택한 언어는 브라우저의 로컬 저장소에 보관합니다. 사이트 데이터를 삭제하거나 언어를 변경할 때까지 유지되며, 변환한 문자 내용은 포함하지 않습니다.

화면 테마 설정

처음에는 기기의 라이트·다크 모드 설정을 따릅니다. 다크 모드 버튼으로 직접 선택하면 브라우저의 로컬 저장소에 선택한 테마만 저장하여 페이지 이동이나 다음 방문에도 적용합니다. 사이트 데이터를 삭제하면 다시 기기의 설정을 따릅니다. 테마 설정에 변환 문자는 포함되지 않습니다.

호스팅과 외부 서비스

이 사이트는 GitHub Pages에서 제공됩니다. GitHub는 서비스 제공과 보호를 위해 IP 주소, 기기 정보 등 요청 정보를 처리할 수 있습니다. 처리 방식, 보관 기간, 개인정보 관련 요청 방법은 GitHub 개인정보처리방침에서 확인할 수 있습니다. Google과 GitHub는 사용자가 거주하는 국가 외의 국가에서도 데이터를 처리할 수 있습니다.

문의와 공개 게시물

문의 페이지는 GitHub Issues로 연결됩니다. 문의를 작성하면 게시물, 사용자 이름, 답변이 공개되며 GitHub에서 처리합니다. 민감한 내용이나 개인정보를 게시하지 마세요.

사용자의 선택

브라우저에서 쿠키와 사이트 데이터를 삭제하거나, 브라우저 기능으로 쿠키 및 애널리틱스 요청을 제한할 수 있습니다. 언어 선택 버튼으로 언어를 바꿀 수도 있습니다. Google은 지원되는 브라우저용 애널리틱스 차단 부가기능도 제공합니다. 사이트 데이터를 삭제하면 저장된 언어 설정이 지워지지만, 외부 서비스에서 이미 처리한 정보까지 삭제되는 것은 아닙니다.

광고와 방침 변경

현재 Decodex에는 광고 배너가 표시되지 않습니다. 광고나 정보 처리 방식이 변경되면 사용하는 서비스를 이 페이지에 반영합니다. 이 방침에 관한 일반적인 질문은 문의 페이지를 이용해주세요.
