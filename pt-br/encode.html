Como codificar texto em Base64

Este codificador transforma o texto original em bytes UTF-8 e gera Base64 padrão. Use para preparar valores para uma API ou conferir o formato esperado por outro sistema.

  1. Digite ou cole o texto original. Inserir uma string já codificada a codifica novamente; use o decodificador para recuperar o original.
  2. A conversão é automática. Se você desativá-la, use o botão de conversão ou Ctrl+Enter (⌘+Enter no Mac).
  3. Copie o resultado com o botão de cópia. O limite é de 5 MB de texto UTF-8.

Alfabeto, preenchimento e tamanho da saída

A saída usa A–Z, a–z, 0–9, +, / e preenchimento = no final, sem adicionar quebras de linha. Para n bytes UTF-8, o tamanho é 4 × ceil(n / 3). Compare f → Zg==, fo → Zm8= e foo → Zm9v. Para Base64URL, substitua + e / por - e _ e siga as regras de preenchimento do protocolo.

Codificar Unicode com UTF-8

Para recuperar caracteres coreanos, acentos ou emojis, o texto original precisa ter sido codificado em UTF-8. Base64 representa bytes e não identifica a codificação. Se o resultado ficar ilegível ou falhar, confira a codificação original. Este conversor não converte automaticamente Shift_JIS, GBK ou outras codificações antigas. Perguntas frequentes

Espaços e quebras de linha são codificados?

Sim. Eles fazem parte dos bytes de entrada. Hello e Hello seguido de uma quebra de linha produzem resultados diferentes. LF e CRLF também geram valores distintos. A decodificação recupera o texto inserido.

Base64 protege meu texto?

Base64 é uma representação reversível dos dados, não uma criptografia. Não protege senhas nem outros segredos.
