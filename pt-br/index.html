Como decodificar texto Base64 online

Decodificar Base64 recupera os bytes representados por uma string. Este decodificador lê esses bytes como UTF-8 para exibir texto, incluindo acentos e emojis. Use para conferir valores de API; ele não baixa imagens ou PDF.

  1. Cole apenas a parte Base64. Remova aspas de JSON e prefixos como data:text/plain;base64, antes da conversão.
  2. A conversão é automática. Se você desativá-la, use o botão de conversão ou Ctrl+Enter (⌘+Enter no Mac).
  3. Copie o resultado com o botão de cópia. O limite é de 5 MB de texto UTF-8.

Formatos Base64 e preenchimento aceitos

Base64 usa + e /; Base64URL usa - e _. Letras e números são iguais. O preenchimento = é uma regra separada: alguns protocolos o removem e outros o mantêm. Uma sequência só de letras e números não revela qual alfabeto foi usado. Nenhum dos formatos é criptografia.

Cada caractere de dados representa seis bits. Três bytes completam 24 bits e quatro caracteres. Acentos e emojis podem ocupar vários bytes UTF-8: 😀 ocupa quatro bytes e produz 8J+YgA==. A tabela compara entradas de um, dois e três bytes.

Zg → f; Zg== → f; 8J-YgA → 😀.

Resolver erros de decodificação Base64

Se uma sequência não for convertida, remova aspas, sinais extras e o prefixo de uma URL de dados; cole apenas a parte Base64. O preenchimento = só pode aparecer no final. Um comprimento com resto 1 na divisão por 4 é inválido. Espaços, quebras de linha e os caracteres Base64URL - e _ são aceitos. Um erro de UTF-8 pode indicar dados binários ou outra codificação: este conversor aceita apenas texto UTF-8.

Perguntas frequentes

Por que o texto fica ilegível ou apresenta erro UTF-8?

Confira a codificação original. Base64 não identifica UTF-8, outras codificações ou dados binários. Este decodificador não converte automaticamente EUC-KR ou Shift_JIS. Adicionar = não resolve esse problema.

Toda sequência Base64 termina com =?

Não. Quando a quantidade de bytes é múltipla de três, nenhum preenchimento é necessário. Outros protocolos o omitem explicitamente.

Base64 protege meu texto?

Base64 é uma representação reversível dos dados, não uma criptografia. Não protege senhas nem outros segredos.
