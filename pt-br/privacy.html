DECODEX

Privacidade

2026-10-03

O Decodex (decodex.fyi), mantido por jinsu100, converte texto no navegador sem guardar um histórico de conversões no servidor. A cópia usa a área de transferência do dispositivo. O Google Analytics pode processar endereços de páginas, referências, horários, navegador, dispositivo, localização aproximada e eventos de uso; utiliza cookies como _ga.

Os eventos incluem sucesso ou erro, modo, idioma, conversão automática ou manual e categorias fixas de erro, nunca o texto, o resultado, seu tamanho ou mensagens de erro. Conversões automáticas são contadas após 1,5 segundo sem alterações. Não coloque segredos nas URLs.

O idioma e o tema escolhidos são salvos localmente; sem uma escolha, são usadas as preferências do navegador ou dispositivo. Você pode limpar os dados do site e bloquear solicitações de análise pelo navegador. O GitHub Pages hospeda o site e pode processar IP e dados das solicitações.

Google e GitHub seguem suas próprias políticas e podem processar dados em outros países; suas configurações determinam a retenção. Mensagens no GitHub Issues são públicas. Atualmente não há anúncios.

Esta página será atualizada se os serviços mudarem. Limpar dados locais não exclui dados já processados por provedores externos.
